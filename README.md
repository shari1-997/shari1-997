## 🚀 Featured Projects

### 1. 🏥 Healthcare Operations Analytics — MySQL + Power BI

**MySQL · SQL · Power BI · Power Query · DAX · Data Modelling**

An end-to-end analytics project exploring appointment operations, patient demographics, billing performance, and payment collections. I created a six-table MySQL database, loaded six synthetic datasets containing **18,800 records**, validated data relationships and financial calculations, and built a four-page interactive Power BI dashboard.

**Dashboard pages**
- **Overview:** appointment volume, completion and cancellation rates, department activity, monthly trends, and waiting times.
- **Booking & Patient Insights:** booking channels, appointment age groups, and all-time patient breakdowns by insurance plan and home region.
- **Billing & Financial Analysis:** billed amount, recorded and posted payments, outstanding balance, collection rate, and billing status.
- **Revenue Trends:** monthly payment collections and monthly billed-versus-posted payment comparisons, with separate year slicers.

**Selected KPIs:** 8,000 appointments · 1,500 all-time patients · 76.48% completion rate · 42.5-minute average wait · 1.51M total billed · 42.9% payment collection rate.

**What this project demonstrates**
- Relational database design and CSV loading with MySQL.
- SQL joins, aggregations, data-quality checks, and financial reconciliation.
- Power BI relationships, DAX measures, interactive slicers, and report design.
- Clear treatment of missing booking-channel and insurance values as **Unknown**.
